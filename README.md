# 中国观鸟记录中心 · 郑四总鸟种首加时间线 & 全量记录一键导出工具

解决官方小程序与网页版的两个痛点：
1. **微信小程序「用户中心 → 郑四总鸟种 → 导出数据」**：可按首次添加时间线导出，但**缺少地点信息**，且无属名分类信息。
2. **网页版 `www.birdreport.cn`**：无法按首次添加时间线导出带地点的鸟种清单，且「观鸟记录」表格受服务端分页限制**只能导出第一页（20 条）**。

本工具直接在已登录的网页版浏览器环境运行（微信扫码登录与小程序数据完全互通），**无需安装 Python、无需抓包、无需手机操作、零外部 CDN 依赖**，自动循环分页拉取全部历史记录并关联首见地点，同时内置 **100% 覆盖郑四版（29 目 / 127 科 / 529 属）** 的中拉丁分类字典，一键生成多工作表 Excel（`.xlsx`）/ CSV / JSON。

## 使用方法（任选其一）

### 方式一：安装油猴脚本（支持一键从 URL 安装与自动更新）

1. 在 Chrome / Edge / Firefox 浏览器中安装 [Tampermonkey（篡改猴）](https://www.tampermonkey.net/) 或 ScriptCat（脚本猫）扩展。
2. 打开 Tampermonkey「管理面板 → 实用工具 → 从 URL 安装」，粘贴以下任意链接并点击安装（已配置 `@updateURL` 与 `@downloadURL`，后续可自动检查更新）：
   - **GitHub Raw（官方更新源）**：`https://raw.githubusercontent.com/Simple53/birdreportHelper/main/birdreport-exporter.user.js`
   - **jsDelivr CDN（国内加速备用）**：`https://cdn.jsdelivr.net/gh/Simple53/birdreportHelper@main/birdreport-exporter.user.js`
3. 打开并登录中国观鸟记录中心：[https://www.birdreport.cn/member/index.html](https://www.birdreport.cn/member/index.html)（支持微信扫码登录）。
4. 页面右下角会自动出现悬浮按钮 **「导出观鸟数据」**，点击即可选择导出格式；面板支持**多账号快速切换**、日期筛选与一键导出。

### 方式二：免安装控制台一键运行（零插件，即贴即用）

1. 浏览器登录中国观鸟记录中心：[https://www.birdreport.cn/member/index.html](https://www.birdreport.cn/member/index.html)。
2. 按 `F12` 打开开发者工具，切换到 **Console（控制台）** 选项卡。
   - *注：Chrome/Edge 首次粘贴代码时若提示禁止粘贴，请先在控制台输入 `allow pasting` 并回车。*
3. 打开本目录下的 `console-export.js`，全选复制并粘贴到控制台回车。
4. 页面会立即弹出导出面板，点击 **「📊 一键导出 Excel (.xlsx)」** 即可自动分页拉取并下载。

## 目录结构

- `birdreport-exporter.user.js`：油猴用户脚本（已内联完整郑四版分类字典）
- `console-export.js`：浏览器 F12 控制台免安装脚本（已内联完整郑四版分类字典）
- `src/core.js`：核心源码（API 分页拉取、AES 解密、时间线与地点聚合、纯 JS OOXML `.xlsx` 生成器、导出面板 UI）
- `taxonomy_zh_dict.json`：郑四版目/科/属中拉丁分类字典（46 目、219 科、529 属，100% 覆盖郑四名录全部属）
- `build.py`：重新打包生成 `birdreport-exporter.user.js` 与 `console-export.js`
- `test_core.mjs`：Node.js 单元测试脚本

## 常见问题

- **为什么不做成自动操作手机微信小程序？**
  小程序与网页版共享同一套后端数据（`api.birdreport.cn`），且小程序的「郑四总鸟种导出」接口本身不含地点字段；在电脑浏览器通过网页版登录态（支持微信扫码登录）调用官方个人中心接口，速度更快、无需手机 USB 调试，也更稳定安全。
- **数据安全说明**
  脚本完全在您本地浏览器运行，仅向官方域名 `api.birdreport.cn` 请求您自己的已登录数据，不会向任何第三方服务器上传账号凭证或观鸟记录。
- **如果导出中途提示「登录已超时」**
  刷新网页重新登录 `www.birdreport.cn` 即可。
